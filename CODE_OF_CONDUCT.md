# Contributor Code of Conduct

**English** | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1.

Be respectful, assume good faith, and keep discussions focused on the work.
Harassment, discrimination, and personal attacks are not acceptable.

Report unacceptable behavior privately to the maintainers. Reports will be
reviewed promptly and handled confidentially.
